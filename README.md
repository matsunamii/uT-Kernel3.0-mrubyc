# TRON × mruby/c リアルタイムスクリプト実行環境

## 概要

本プロジェクトは、NUCLEO-H533RE上のμT-Kernel 3.0 BSP2で軽量Ruby処理系mruby/cを動作させ、Rubyによる組込みアプリケーションを開発できる実行環境です。
一般的なRTOSアプリケーションはC言語で開発されますが、本プロジェクトではμT-Kernel 3.0へmruby/cを導入することで、Rubyによる簡潔な記述でRTOSアプリケーションを開発できます。
また、mruby/c独自のタスク管理機能は使用せず、RubyスクリプトはRTOSタスクとして実行されます。タスクの生成・待機・スケジューリングはすべてμT-Kernel 3.0が担当し、mruby/cはRubyバイトコードを解釈・実行する仮想マシンとして利用しています。さらに、TimeクラスはRTOSが管理するシステム時刻と連携しており、RTOSの時間管理機能をRubyから利用できます。

## デモアプリケーション
動作確認用として、以下のRubyアプリケーションを用意しています。

### デジタル時計
7セグメントLEDへ現在時刻を表示します。
Timeクラスを利用し、RTOSが管理する時刻を取得しています。

### ストップウォッチ
ボタン入力によるスタート・ストップ・リセット機能を実装しています。
TimeクラスとGPIOクラスを利用したサンプルです。

これらのデモを通して、Rubyによる簡潔な記述でありながら、μT-Kernel 3.0のタスク管理や時間管理を活用した組込みアプリケーションを開発できることを確認できます。

## ドキュメント

本プロジェクトでは、実行手順、操作方法、開発者向けの拡張方法、動作確認方法を `docs/` ディレクトリにまとめています。
各ドキュメントの役割は以下の通りです。

### セットアップ・実行手順書

`setup_and_run_guide.md` では、本プロジェクトを実行するための一連の手順を説明しています。  
GitHubからプロジェクトをZIP形式でダウンロードし、STM32CubeIDEにインポートしてビルド・デバッグ実行し、シリアル出力を確認するまでの流れを記載しています。

### 開発者向けガイド

`developer_guide.md` では、本プロジェクトを拡張するための方法を説明しています。  
新しいRubyプログラムの追加方法、Rubyスクリプトをmruby/c用バイトコードとして組み込む方法、C言語側で実装した関数をRubyメソッドとして登録する方法、Rubyタスクを追加する方法などを記載しています。  
また、μT-Kernelのアラーム機能を用いたmruby/c VMのプリエンプション制御の仕組みについても説明しています。
